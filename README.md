# Projeto ONG

Projeto desenvolvido para monitorar a comunicação entre uma aplicação frontend e uma API backend.

## Tecnologias utilizadas

- Vite
- JavaScript
- Node.js
- Express
- Dotenv

## Requisitos

- Node.js instalado
- npm instalado
