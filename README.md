# Projeto ONG

Projeto desenvolvido para monitorar a comunicação entre uma aplicação frontend e uma API backend.

## Tecnologias utilizadas

- Vite
- JavaScript
- Node.js
- Express
- Dotenv

## Requisitos

- Node.js instalado
- npm instalado

## Instalação

Clone o repositório:

```bash
https://github.com/Pedro-Sotelle26/projeto-ong.git
```

## API

O projeto possui uma API desenvolvida com Node.js e Express.

### Verificar saúde da API

Endpoint: GET /api/health

Resposta esperada:

{
"status": "ok"
}
